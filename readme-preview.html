需要 macOS 14+、Codex 桌面端，以及 iPhone 上的 Bark。

安装 CoPing

从 GitHub Releases 下载 DMG，把 CoPing 拖进应用程序文件夹。

填入 Device Key

在 Bark 首页复制 Device Key，回到 CoPing 保存并发送测试通知。

连接 Codex

进入“设置 → Codex”，连接 Hook 并在 Codex 中确认信任。

这版没有假装无所不能。

CoPing 现在只负责把需要你注意的时刻送到手机。

手机上批准操作、回答 Codex、远程控制和执行失败通知还没有实现。范围明确，通知链路才能保持简单、可查和可信。
