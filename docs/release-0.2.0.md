# CoPing 0.2.0 发布验证与迁移

日期：2026-09-24。此次发布为兼容性改进，**不是所有 Codex 生命周期的完整兼容认证**。

## 改动

- 按调用和阶段处理问题提醒，默认旧提问订阅补齐 Pre/Post 取消闭环；Stop 不再无差别清理等待。
- 审批提醒仅在身份与等待阶段可关联时去重；清理关联计时任务，投递前复核任务资格和代次。单项审查超时不再污染连接健康状态。
- 恢复通知时恢复必要监控，保留当前等待并过滤历史状态；旧事件重放采用稳定身份。
- 连接来源与 Helper 升级校验、配置保留和失败恢复更明确；IPC 版本 1 与状态协议版本 11 校验保留。
- 设置页将技术信息收进默认折叠的“高级设置与诊断”，将扩展选项改称“新版问题卡片提醒”，默认关闭。
- 产品仍只发通知，不提供手机回复、远程执行或远程审批。

## 发布前自动验证

```sh
DEVELOPER_DIR=/Library/Developer/CommandLineTools \
SDKROOT=/Library/Developer/CommandLineTools/SDKs/MacOSX26.5.sdk \
bash script/test.sh
```

PASS：ReleaseVersionTests、warnings-as-errors 产品构建、CoPingSelfTests、六项生产组件生命周期回归 R1–R6（含防漏报反例）。本地测试使用临时配置、模拟投递与本地测试 socket，不修改真实 Codex 配置。六项修复前 FAIL 与修复后 PASS 证据见 [复审报告](regression-six-review.md)。CLT 链接器仍有缺失搜索目录/arclite 警告；Swift 编译与测试通过。默认 Xcode 许可未接受，未替用户改变该状态。

发布包使用 `script/package_adhoc_release.sh`，版本来自发布标签，构建号来自提交计数。该脚本校验 App、ZIP 解包和 DMG 挂载后的签名完整性，并生成 SHA-256。**Ad-hoc 签名，不是 Developer ID 签名或 Apple 公证包**；首次打开可能需要用户在系统安全设置中允许。

## 已知限制与手工验收

1. 完成提醒仍来自 Stop 候选。Codex 随后继续运行时可能提前提醒；根任务终态、Interrupt、SessionEnd 和子代理生命周期尚未完整接入（CP-03 BLOCKED）。
2. 异步 `accepted` 仅表示问题已呈现，不代表用户已经回答。未知回答结果不擅自取消；部分宿主可能在快速回答后仍收到提醒。
3. 仅适配审批状态版本 11；未知版本保守降级。人工审批、自动审查转人工、连接断开重连仍需受控实机验收。
4. 尚未覆盖所有旧版宿主、组织策略、自定义 Home、真实签名失败及升级回退场景；本轮手工升级使用本地 ad-hoc 测试包。

## 升级

退出旧 CoPing，替换为 0.2.0。打开后在 Codex 设置按提示修复连接、审核 CoPing 的 Hook，再新建 Codex 对话验证。新版问题卡片没有提醒时，断开连接，在“高级设置与诊断”开启“新版问题卡片提醒”，重新连接并按提示审核。保留旧 App 和配置备份；回退仅处理 CoPing 自有配置，不覆盖第三方 Hook。详见 [升级与回退](upgrade-and-rollback.md)。
